# Smith2006_coordinates

The two CSV files in this folder are not a public download - they were
kindly shared directly by Dr. Jo Smith (josmith@mvarc.eu), one of the
primary authors of the underlying 2006 study, in response to a request for
the original site coordinates.

Without this data, the sample points associated with this study would have
had to be dropped during the biodiversity dataset curation step, since the
coordinates published in the original source were not usable as-is. Thank
you, Jo, for making it possible to keep these sites in the dataset.

- `Smith2006_coodinates_from_author.csv` - associated habitat coordinates
- `Smith2006_coordinates_from_author_edges.csv` - associated edge/boundary coordinates.
