# Cropland extent 

- Source:	Liao, Y., Chen, S., Bai, Y., Wang, J., & Gong, P. (2026). 
  Global 30-m annual cropland extent dynamics (2000–2024): A consistent baseline 
  of structural evolution and regional disparities. ESSD – Anthroposphere/Land cover and land use. 
  https://doi.org/10.5194/essd-2025-838
  
- Download link: doi.org/10.5281/zenodo.18199675

- Expected files: When accessing the link, multiple .zip folders, named according to longitud and latitude variations
  (example: "lon_+000_to_+006.zip") will be available. Download all, and open all the zip files. 
  Add the FOLDERS (which will contain files names as "Crop_-3.0_3.0.tif") to this folder. 

Download the data from the source above and place the folders directly in this
folder (`Databases/Cropland_Liao/`) so the scripts can find them at the paths they expect.
