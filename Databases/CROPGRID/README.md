# CROPGRIDS

- Source: [66].	Tang, F. H. M., Nguyen, T. H., Conchedda, G., Casse, L., Tubiello, F. N., & Maggi, F. (2024). 
  CROPGRIDS: A global geo-referenced dataset of 173 crops. Scientific Data, 11(1), 413. 
  https://doi.org/10.1038/s41597-024-03247-7
  
- Download link: https://figshare.com/articles/dataset/CROPGRIDS/22491997/7

- Expected files: When downloading, a zip folder will be obtained. After opening, open also subfolder "CROPGRIDSv1.08_NC_maps.zip" 
  There, 173 files named CROPGRIDSv1.08_<crop>.nc (one file per crop) will be available.
  All those files should be put in this folder

Download the data from the source above and place the files directly in this
folder (`Databases/CROPGRID/`) so the scripts can find them at the paths they expect.
