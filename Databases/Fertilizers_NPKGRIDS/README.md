# NPKGRIDS fertilizer application

- Source: Nguyen, T. H., Tang, F. H. M., Conchedda, G., Casse, L., Obli-Laryea, G., Tubiello, F. N., & Maggi, F. (2024). 
  NPKGRIDS: A global georeferenced dataset of N, P2O5, and K2O fertilizer application rates for 173 crops. Scientific Data, 11(1), 1179. 
  https://doi.org/10.1038/s41597-024-04030-4
  
- Download link: https://figshare.com/articles/dataset/NPKGRIDS/24616050
  
- Expected files: Dawnload all files ("Dawnload all" button). Open the .zip file that will be downloaded. 
  There, a sub .zip file named "NPKGRIDSv1.08_NC.zip" will contain 173 files as NPKGRIDSv1.08_<crop>.nc (one file per crop)
  Open it and take all those 173 files and place them in this folder.

Download the data from the source above and place the files directly in this
folder (`Databases/Fertilizers_NPKGRIDS/`) so the scripts can find them at the paths they expect.
